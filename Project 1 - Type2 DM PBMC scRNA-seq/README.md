# T2D PBMC scRNA-seq Analysis

Independent computational analysis of publicly available single-cell RNA-seq data from peripheral blood mononuclear cells (PBMCs) from healthy individuals and patients with type 2 diabetes (T2D).

This project uses the scRNA-seq component of **GSE268210** and focuses on quality control, doublet detection, dimensionality reduction, clustering, marker identification, and automated cell-type annotation.

> **Important:** The biological samples, experimental design, sequencing experiments, and primary data generation were performed by the original investigators. This repository contains an independent computational analysis of their publicly available data and does not claim ownership of the original experiment or dataset.

## Data Source

The dataset was obtained from the **NCBI Gene Expression Omnibus (GEO)**:

- **GEO accession:** GSE268210
- **BioProject:** PRJNA1115130
- **Organism:** *Homo sapiens*
- **Platform:** Illumina HiSeq 2500
- **Data type analyzed:** 10x Genomics scRNA-seq
- **Biological material:** Peripheral blood mononuclear cells (PBMCs)

The original study includes scRNA-seq, scTCR-seq, and scBCR-seq data. This repository analyzes the **scRNA-seq component** of the study.

## Analysis Workflow

The computational workflow consists of:

1. Raw count matrix preparation
2. Quality control
3. Cell filtering
4. Doublet detection with `scDblFinder`
5. Doublet removal
6. Log-normalization
7. Highly variable gene selection
8. Scaling
9. Principal component analysis (PCA)
10. Nearest-neighbor graph construction
11. Unsupervised clustering
12. UMAP dimensionality reduction
13. Cluster marker identification
14. Hierarchical automated cell-type annotation with `SingleR`
15. Annotation using the Human Primary Cell Atlas reference
16. Canonical marker-based annotation validation
17. Generation of summary tables and figures

The main analysis is implemented in R.

Detailed commands and parameters are provided in the analysis script.

## Project Status

**Project 1 — T2D PBMC scRNA-seq Analysis**

This project is the first part of a broader single-cell RNA-seq analysis portfolio.

The planned portfolio consists of:

- **Project 1:** Independent analysis of the T2D PBMC cohort
- **Project 2:** Independent analysis of a separate healthy PBMC cohort
- **Project 3:** Comparative and integrated analysis of the T2D and healthy cohorts

The projects are designed to progressively build from independent dataset analysis toward cross-cohort comparison and downstream biological interpretation.
