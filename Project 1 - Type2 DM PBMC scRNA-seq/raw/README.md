# Raw Data

This directory contains the raw single-cell RNA-seq data files downloaded from the publicly available **GSE268210** dataset in the NCBI Gene Expression Omnibus (GEO).

## Data Source

- **GEO accession:** GSE268210
- **BioProject:** PRJNA1115130
- **Organism:** *Homo sapiens*
- **Biological material:** Peripheral blood mononuclear cells (PBMCs)
- **Data type used in this project:** 10x Genomics scRNA-seq

The original GSE268210 study includes scRNA-seq, scTCR-seq, and scBCR-seq data. This project uses the **scRNA-seq component** of the study.

## Original Study

Gu D, Lim J, Han KY, Seo I, Jung D, Park W.

*Single-cell analysis of human PBMCs in healthy and type 2 diabetes populations: Dysregulated immune networks in type 2 diabetes unveiled through single-cell profiling.*

**PMID:** 39072276

The original biological samples, experimental procedures, sequencing experiments, and primary data generation were performed by the original investigators.

**The data in this directory were not generated by this project and are not claimed as original data.**

## Contents

The raw data are organized into directories corresponding to the individual samples used in the analysis.

The files include:

- `matrix.mtx.gz` — sparse gene expression count matrix
- `barcodes.tsv.gz` — cell barcode identifiers
- `features.tsv.gz` — gene and feature information
- Sample-specific metadata files where provided by the original dataset

The exact filenames and organization reflect the files obtained from the original GEO dataset.

## Data Processing

The files in this directory represent the raw input data used for the computational analysis.

They were used to construct the Seurat object and subsequently processed through quality control, doublet detection, normalization, dimensionality reduction, clustering, marker identification, and automated cell-type annotation.
