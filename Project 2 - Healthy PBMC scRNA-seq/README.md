# Healthy PBMC scRNA-seq Analysis

Independent computational analysis of publicly available single-cell RNA-seq data from peripheral blood mononuclear cells (PBMCs) from healthy individuals.

This project uses the healthy-donor component of **GSE318371** and focuses on quality control, doublet detection, dimensionality reduction, clustering, marker identification, and automated cell-type annotation.

The original GSE318371 study includes both healthy donors and patients with newly diagnosed NK/T-cell lymphoma. This repository analyzes **only the 12 healthy PBMC donors** from that study.

> **Important:** The biological samples, experimental design, donor recruitment, sample processing, sequencing experiments, and primary data generation were performed by the original investigators. This repository contains an independent computational analysis of their publicly available data and does not claim ownership of the original experiment or dataset.

## Data Source

The dataset was obtained from the **NCBI Gene Expression Omnibus (GEO)**:

- **GEO accession:** GSE318371
- **BioProject:** PRJNA1370270
- **Organism:** *Homo sapiens*
- **Data type analyzed:** 10x Genomics scRNA-seq
- **Biological material:** Peripheral blood mononuclear cells (PBMCs)
- **Analyzed population:** 12 healthy donors
- **Sequencing platform:** Illumina NovaSeq X Plus

The original study contains scRNA-seq data from **12 healthy donors and 20 patients with newly diagnosed NK/T-cell lymphoma (NKTCL)**. This repository analyzes only the healthy-donor PBMC subset.

## Analysis Workflow

The computational workflow consists of:

1. Raw count matrix preparation
2. Quality control
3. Cell filtering
4. Doublet detection with `scDblFinder`
5. Doublet removal
6. Log-normalization
7. Highly variable gene selection
8. Scaling
9. Principal component analysis (PCA)
10. Nearest-neighbor graph construction
11. Unsupervised clustering
12. UMAP dimensionality reduction
13. Cluster marker identification
14. Hierarchical automated cell-type annotation with `SingleR`
15. Annotation using the Human Primary Cell Atlas reference
16. Canonical marker-based annotation validation
17. Generation of summary tables and figures

The main analysis is implemented in R.

Detailed commands and parameters are provided in the analysis script.

## Project Status

This project is the second part of a broader single-cell RNA-seq analysis portfolio.

The planned portfolio consists of:

- **Project 1:** Independent analysis of the T2D PBMC cohort
