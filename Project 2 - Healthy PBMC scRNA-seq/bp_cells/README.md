# BPCells Matrix

This directory contains the **BPCells-backed RNA count matrix** generated during the computational analysis of the publicly available **GSE318371** scRNA-seq dataset.

## Purpose

The count matrix was converted to a BPCells-backed representation to enable more memory-efficient handling of the large single-cell dataset.

The BPCells matrix is a **derived computational representation** and is not the original sequencing dataset.

## Contents

- `healthy_RNA_counts/` — BPCells-backed RNA count matrix
- `README.md` — documentation for this directory

## Source

The matrix was derived from the scRNA-seq data from:

**GEO:** GSE318371  
**BioProject:** PRJNA1370270  
**PMID:** 42370195  
**DOI:** 10.7150/thno.132582

Original study:

Liang X, et al.

*Peripheral blood immune profiling reveals key signatures in newly diagnosed NK/T cell lymphoma patients.*

The original biological samples, experiments, and sequencing data were generated by the original investigators. This repository contains an independent computational analysis and does not claim ownership of the original data.

This project uses the **12 healthy-donor samples** from the publicly available GSE318371 dataset.
