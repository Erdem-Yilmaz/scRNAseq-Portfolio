# Raw Data

This directory contains the raw single-cell RNA-seq data files downloaded from the publicly available **GSE318371** dataset in the NCBI Gene Expression Omnibus (GEO).

## Data Source

- **GEO accession:** GSE318371
- **BioProject:** PRJNA1370270
- **Organism:** *Homo sapiens*
- **Biological material:** Peripheral blood mononuclear cells (PBMCs)
- **Data type used in this project:** 10x Genomics scRNA-seq
- **Analyzed population:** 12 healthy donors

The original GSE318371 study includes scRNA-seq data from both healthy donors and patients with newly diagnosed NK/T-cell lymphoma (NKTCL). This project uses **only the scRNA-seq data from the 12 healthy donors**.

## Original Study

Liang X, et al.

*Peripheral blood immune profiling reveals key signatures in newly diagnosed NK/T cell lymphoma patients.*

**PMID:** 42370195  
**DOI:** 10.7150/thno.132582  
**GEO:** GSE318371  
**BioProject:** PRJNA1370270

The original biological samples, donor recruitment, experimental procedures, sequencing experiments, and primary data generation were performed by the original investigators.

**The data in this directory were not generated by this project and are not claimed as original data.**

## Contents

The raw data are organized into directories corresponding to the individual healthy samples used in the analysis.

The files include:

- `matrix.mtx.gz` — sparse gene expression count matrix
- `barcodes.tsv.gz` — cell barcode identifiers
- `features.tsv.gz` — gene and feature information
- Sample-specific metadata files where provided by the original dataset

The exact filenames and organization reflect the files obtained from the original GEO dataset.

## Data Processing

The files in this directory represent the raw input data used for the computational analysis.

They were used to construct the Seurat object and subsequently processed through quality control, doublet detection, normalization, dimensionality reduction, clustering, marker identification, and automated cell-type annotation.

BPCells was additionally used for memory-efficient handling of the large gene expression matrix during downstream marker analysis.
