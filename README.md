# scRNA-seq Analysis Portfolio

A portfolio of reproducible single-cell RNA-seq analyses using publicly available datasets.

## Projects

### Project 1 — Type 2 DM PBMC scRNA-seq
Independent computational analysis of a publicly available T2D PBMC scRNA-seq cohort.

### Project 2 — Healthy PBMC scRNA-seq
Independent analysis of a separate healthy PBMC cohort.

### Project 3 — T2D vs Healthy PBMC
Comparative and integrated analysis of the T2D and healthy PBMC cohorts.
